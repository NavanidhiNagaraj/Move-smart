# 🚗 MoveSmart

## Intelligent Multi-Modal Transportation Recommendation System

MoveSmart is an intelligent transportation assistant designed to help users make informed travel decisions by comparing different modes of transport based on their priorities. Instead of simply displaying available routes, the system recommends the most suitable travel option by analyzing cost and user preference.

The platform allows users to choose between **Cheapest** and **Comfort** modes. For cost-sensitive travel, MoveSmart compares metro fares with ride-hailing services to recommend the most economical option. For users prioritizing convenience, the system compares multiple auto providers and recommends the best available choice while providing clear navigation guidance.

---

## Key Features

* Intelligent travel recommendation based on user preference
* Cheapest Mode for cost-optimized travel
* Comfort Mode for convenient travel recommendations
* Fare comparison between Metro and Auto
* Comparison of multiple ride-hailing providers
* Metro station guidance with destination information
* Estimated travel cost and route information
* User-friendly and responsive interface

---

## System Workflow

1. User enters the source and destination.
2. User selects either **Cheapest** or **Comfort** mode.
3. The system analyzes available transportation options.
4. Fare estimates are compared across supported services.
5. The optimal recommendation is generated.
6. Metro guidance, destination station, and travel details are displayed when applicable.
